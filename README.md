# Manling Zhang — Software Engineer Portfolio

A responsive single-page portfolio built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in your browser. The Google Fonts stylesheet requires an internet connection; the page still works with fallback fonts offline.

## Publish with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to its main branch.
3. Go to **Settings → Pages** and choose **Deploy from a branch**, `main`, `/ (root)`.
4. Your site will be available at `https://vera-zhangml.github.io/portfolio/` after deployment.

## Customize
- Replace sample project visuals with real screenshots when available.
- Add a verified LinkedIn URL and resume PDF if desired.
- Update technical experience and project links as projects evolve.
