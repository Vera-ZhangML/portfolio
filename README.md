# Manling Zhang — Software Engineer Portfolio

A personal portfolio built with HTML, CSS, and JavaScript to showcase my projects, experience, and progress toward a software engineering career.

## Featured Projects

### Visitor Management System
A team project for managing visitor check-in and check-out. My contributions included the Visitor Kiosk frontend and backend, GitHub Actions CI/CD, and SendGrid email notifications.

### PawMatch
An ongoing dog adoption project developed with AI assistance. Current work includes project requirements and scope, desktop and mobile Figma prototypes, an initial HTML/CSS/JavaScript version, and a local React demo that displays dog profiles from an Express API.

### Washington State Wildfire Preparedness Dashboard
A hackathon project developed with AI assistance. Uses Python to prepare data and an interactive dashboard with a Leaflet map and charts to explore wildfire patterns in Washington State.

- HTML
- CSS

- Google Fonts

Individual projects use additional technologies described in their project sections.

1. Download or clone this repository.

Project links and demos are included where available. Some applications currently run locally, and ongoing projects may have features that are still in development.
